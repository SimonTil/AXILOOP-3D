# AXILOOP-3D

AXILOOP-3D is Axiloop's slicer for FDM 3D printers. It is based on [OrcaSlicer](https://github.com/OrcaSlicer/OrcaSlicer) and has the same features. Website: https://www.axiloop3d.com/

## Download

Windows builds are on the [Releases page](https://github.com/SimonTil/AXILOOP-3D/releases). Linux and macOS builds aren't available yet.

## Differences from OrcaSlicer

- Axiloop name, logo and colours (navy blue accent; light or dark mode follows the Windows setting on first start). Settings are stored in `%APPDATA%\AXILOOP-3D`, so AXILOOP-3D can be installed next to OrcaSlicer.
- Stealth Mode is on by default: no Orca Cloud and no Bambu Cloud until you turn it off in the preferences. The check for new AXILOOP-3D versions stays on. The cloud login panel on the home page is hidden too; turn off "Hide login side panel" in the preferences to show it.
- The update check, release notes and bug reports point to this repository. Help and wiki links still go to the [OrcaSlicer wiki](https://www.orcaslicer.com/wiki), which isn't maintained by Axiloop; the links in the app say so.
- The first G-code line still reads `; generated by OrcaSlicer <version>`, so Klipper (Moonraker) recognises the slicer. A second line names AXILOOP-3D and its version.
- AXILOOP-3D has its own version number, starting at 0.1.0 (1.0.0 once the Axiloop printer profiles are added). The About window shows which OrcaSlicer version it's based on.

Every changed file is listed with the reason in [axiloop/CHANGED_FILES.md](axiloop/CHANGED_FILES.md).

## Klipper note

If your printer runs Klipper, add this to `printer.cfg` to enable object exclusion and arc support:

```gcode
[exclude_object]

[gcode_arcs]
resolution: 0.1
```

## Building

AXILOOP-3D builds the same way as OrcaSlicer: see [OrcaSlicer Wiki - How to build](https://www.orcaslicer.com/wiki/how_to_build). On Windows, run `build_win.bat -d -s --installer` (`-h` lists all options; `build_win.bat -u` installs CMake, Perl and Git). The program ends up in `build\OrcaSlicer`, the installer in `build\`.

## Following OrcaSlicer

- `main` is an unchanged mirror of OrcaSlicer's `main`.
- The work branch `axiloop-3d` is based on OrcaSlicer release tags (currently `v2.5.0`). A patch release is merged in with `git merge <tag>`; a new minor release needs the steps in "Merge tips" in `axiloop/CHANGED_FILES.md`.
- After a merge, run `axiloop/rebrand_translations.ps1` and `axiloop/rebrand_colors.ps1` again. The branding images are generated with `axiloop/branding/make-branding.ps1`.
- [axiloop/CHANGED_FILES.md](axiloop/CHANGED_FILES.md) lists the files where merge conflicts can occur.
